# Sequence • Flow Sequencer ✦

A modern, temporal focus sequencer built to eliminate **"The Momentum Cliff"** — keeping you in flow when starting work on your PC.

Inspired by Notion's typography and Linear's electric blue aesthetic.

---

## ✨ Features

- **Now Focusing Card**: Focus on only one task at a time with a live stopwatch.
- **Embedded Notion Scratchpad**: Write quick markdown notes, links, and scratch text directly attached to each task — no need to open Notepad!
- **Auto-Propelling Sequence**: Press `Space` or click **"Done & Next"** to trigger a confetti burst, an uplifting audio chime, and automatically promote the next task.
- **Proactive OS Notifications**: Sends desktop alerts to remind you what's next when a task is completed, even if the window is in the background.
- **Gentle Temporal Nudge**: Configurable interval (5m, 10m, 15m, 25m) that gently chimes and nudges you if you get stuck or drift away.
- **Keyboard-First Workflow**:
  - `Space` : Mark current task complete & advance
  - `Enter` : Add new task into the sequence
  - `?` : Open Keyboard Shortcuts cheatsheet
- **Installable PWA**: Click "Install" in your browser address bar to run it as a standalone desktop app in your Linux dock.
